# Assimilation Windows onboarding

Windows onboarding describes prerequisites before a separately authorized installation.

## Language

**Explicit Git check**:
An optional observation of the version reported by a trusted Git executable selected by the operator. It is separate from automatic Git discovery.
_Avoid_: Automatic Git detection

**Observed Git version**:
The version returned by an explicit Git check. It does not establish compatibility with Assimilation's source operations.
_Avoid_: Qualified Git installation
