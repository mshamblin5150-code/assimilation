# Admission before the examination starts

Return factual answers to Number One. This is an exposure/tool check, not a graded
engineering question. No deadline or attempt starts until receipt is confirmed.

1. Have you previously seen this artifact, challenge, its private evaluation
   material, or a substantially matching solution? State what and when, or unknown.
2. Which OS, existing authorized interpreter/tool versions, editor/agent and Git
   tools can you use? Confirm that `python --version` or your equivalent names a
   real existing Python 3.12+ for the supplied artifact. Do not install anything
   to answer this check. Report genuine access/environment failures.
3. Can you lawfully use those tools and your own chosen GitHub account/repository,
   and authorize access for a separate reviewer? You retain the destination choice.
4. Declare intended AI/human/tool assistance and any relevant restrictions. Such
   assistance is permitted when authorized and attributed; you remain responsible
   for decisions and must demonstrate the understanding required by the contract.

Prior exposure or missing tools triggers an examiner decision before admission,
not an accusation or an automatic failing grade. Artifact inspection in the exam
is expected after admission. The instructor key must remain undisclosed.
