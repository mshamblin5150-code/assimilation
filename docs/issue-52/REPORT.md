## Technology and security conclusions

All three requested frameworks support speaker embedding/comparison workflows. pyannote is not merely diarization. Direct WeSpeaker is a credible additional candidate. Framework and model-weight licenses differ. CPU-local inference is documented; target-machine performance is untested.

Recommend SpeechBrain ECAPA for a first reviewed acoustic experiment. Coordinator and security reviewer independently spot-checked its pinned scorer: cosine similarity is compared above a threshold; the file helper does not forward a custom threshold. Model configuration also carries constructor tags and a mutable nested acquisition path. Neither source pins nor upstream file hashes establish safe, locally verified executable artifacts.

Speaker matching cannot prove the Captain's identity. Random challenges are fallible against synthesis. NIST SP800-63B-4 excludes voice comparison from its authentication requirements; this research remains supplemental and makes no conformity claim. In a future gateway, a visiting agent should request verification, not download biometric templates or encryption keys. A trusted receiving host must validate the independent authenticator result and its request/audience binding, then apply its own permissions. A hostile host cannot be made trustworthy by a displayed verification badge.

Five blockers remain before acoustic execution:
1. Reviewed dependency, weight and configuration manifest, complete hashes and loader review.
2. Immutable local resolution with no constructor/implicit-fetch surprises.
3. Exact synthetic generator, voice provenance and license clearance.
4. Frozen calibration, held-out and attack lists/counts with explicit failure accounting.
5. Concrete expiry, cache/temp/crash/snapshot cleanup inventory and execution-host isolation evidence.

Security reviewer challenged the candidate directly and confirmed these holds. Seven architecture corrections are detailed in the separate security record. No unresolved operator product choice is needed to continue the listed research corrections.
