# What to tell Chad

> I've published an open-source starter repository called **Assimilation** that gathers a practical approach to using AI for engineering. Start with its README. If you just have ChatGPT, ask it to read the Markdown instructions or upload the files yourself. The actual complete Matt Pocock and P-Stack reference files are browsable under upstream/. If you have a coding agent and Git/Python, clone the repo, verify the source snapshot, and optionally follow the README install command for host bridges. Copying source does not activate plugins or execute instructions. Then tell your AI what you want to build in ordinary words. It should ask questions, document important decisions as ADRs, use Wayfinder if the project is genuinely big and uncertain, and show you verifiable work. You remain in charge.

If Chad's model cannot read files, access the web, install plugins, or run code, it should explain that fact—not act as if “assimilate” created new capabilities. The same doctrine still helps with planning and communication.

A custom Chief of Staff is optional. One agent may do all coordination for a small job. Chad need not know Number One's private history.
